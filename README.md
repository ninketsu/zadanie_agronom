# Цифровой агроном: прогноз урожайности с помощью ИИ

**Команда:** ГенИИ  
**Направление:** Большие данные и искусственный интеллект  
**Участники:** Гарайшина Азалия Ринатовна, Гарайшина Аделия Ринатовна  
**Наставник:** Фадеева Лаура Витальевна, педагог дополнительного образования

Нейросеть, построенная и обученная в среде **NNTrack**, прогнозирует урожайность
сельскохозяйственной культуры (задача **регрессии**) по шести признакам: регион, культура, год,
среднегодовые осадки, объём пестицидов и средняя температура.

**Результат финальной модели на проверочной выборке (5 144 строки, не участвовали в обучении):**
R² = **0.985**, MAE = **0.051** (≈ 0.51 т/га), RMSE = **0.104** (≈ 1.04 т/га).
Для сравнения: прогноз «всегда среднее значение» даёт MAE 0.631, линейная модель — R² 0.07.

## Необходимое ПО

| Для чего | Что нужно |

| Открыть и дообучить проект | NNTrack 2.3.1 (Windows 10/11, x64) |
| Запустить модель без NNTrack | Python 3.9+ и пакеты `torch>=2.0`, `numpy>=1.24` |

## Установка и запуск

```bash
git clone <ссылка на этот репозиторий>
cd <папка репозитория>
python -m pip install -r requirements.txt
```

**Прогноз по CSV-файлу** (6 столбцов признаков; заголовок необязателен):

```bash
python src/predict.py --input examples/input_example.csv --output predictions.csv
```

**Прогноз для одного набора признаков** (6 чисел в порядке Area, Item, Year, осадки, пестициды, температура):

```bash
python src/predict.py --values 0.5 0.333 0.952 0.45 0.012 0.62
```

**Метрики и анализ ошибок** (воспроизводит разбиение NNTrack: `random_split`, seed 123, 20 % на проверку):

```bash
python src/evaluate.py
```

Если в CSV есть седьмой столбец с фактической урожайностью (`examples/input_with_actual.csv`),
`predict.py` дополнительно выводит ошибку по каждой строке и R², MAE, RMSE.

### Использование модели в своём коде

```python
import torch
model = torch.jit.load("model/model.torchscript").eval()
x = torch.tensor([[0.4646, 0.4444, 0.2857, 0.2449, 0.2163, 0.1985]])  # 6 признаков как в датасете
print(model(x))  # hg/ha_yield в шкале датасета (1.0 = 10 т/га)
```

Модель принимает признаки **в том виде, как в датасете** (значения 0–1) и возвращает урожайность
в шкале датасета — дополнительная нормализация не нужна.

## Решение

- **Данные:** 25 723 строки, 6 признаков (уже масштабированы в 0–1), целевая переменная `hg/ha_yield`.
- **Эксперименты:** 4 архитектуры при одинаковых условиях (Adam, lr 0.001, пакет 128, до 300 эпох,
  одна проверочная выборка 20 %) — от линейной модели (R² 0.07) до сети 512 → 512 → 256 → 128 (R² 0.985).
  Полная таблица — `docs/experiments.md`.
- **Финальная модель:** эксперимент 3, 430 593 параметра; R² на обучении 0.993, на проверке 0.985 —
  явного переобучения нет.
- **Анализ ошибок:** больше всего ошибается на высокоурожайных культурах (картофель, бананы-плантайн),
  в процентах от урожая — 4–8 % у клубнеплодов и 15–18 % у сорго и сои; крупнейшие промахи — редкие
  аномальные скачки урожая. Подробно — `docs/error_analysis.txt`.
- **Ограничения:** модель знает только регионы и культуры из датасета; для лет после 2011 и аномальных
  урожаев прогноз менее надёжен; 9 из 25 723 прогнозов отрицательные (`predict.py` выводит их как 0 т/га).
