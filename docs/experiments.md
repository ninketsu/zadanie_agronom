# Таблица экспериментов

Все эксперименты проведены в NNTrack 2.3.1 (проект «Большие данные», задача «Регрессия»)
на файле `data/yield_df_training_scaled.csv` без изменений.

**Общие условия (одинаковые во всех экспериментах):**

| Параметр | Значение |
|---|---|
| Признаки | 6: Area, Item, Year, average_rain_fall_mm_per_year, pesticides_tonnes, avg_temp |
| Целевая переменная | hg/ha_yield (в признаки не входит) |
| Разбиение | случайное, NNTrack `random_split`, seed 123: 20 579 строк обучения / 5 144 проверки |
| Оптимизатор | Adam, скорость обучения 0.001 |
| Размер пакета | 128 |
| Эпохи | до 300 |
| Функция потерь / метрика | MSE / R² (NNTrack стандартизирует целевую переменную при обучении) |
| EarlyStopping | monitor = val_loss, min_delta = 0.0001, patience = 30 |
| Архитектура | последовательная: Linear (Dense) + ReLU, выход Linear(1) без активации |

**Результаты (значения из окна обучения NNTrack):**

| № | Скрытые слои | Параметров | Эпох | Потери обуч. | Потери пров. | R² обуч. | R² пров. |
|---|---|---|---|---|---|---|---|
| 0 | нет (линейная модель) | 7 | 97* | 0.6416 | 0.6530 | 0.0839 | 0.0727 |
| 1 | 64 → 32 | 2 561 | 300 | 0.0546 | 0.0665 | 0.9220 | 0.9097 |
| 2 | 256 → 256 → 128 | 100 609 | 300 | 0.0081 | 0.0143 | 0.9885 | 0.9798 |
| **3** | **512 → 512 → 256 → 128** | **430 593** | **300** | **0.0046** | **0.0110** | **0.9934** | **0.9846** |

\* обучение остановлено EarlyStopping.

**Финальная модель — эксперимент 3**: лучшие потери и R² на проверочной выборке,
разрыв между обучением и проверкой небольшой (R² 0.993 → 0.985), явного переобучения нет.

**Метрики финальной модели в шкале датасета** (экспорт TorchScript, `python src/evaluate.py`):

| Выборка | R² | MAE | RMSE |
|---|---|---|---|
| Обучение | 0.9941 | 0.0382 | 0.0642 |
